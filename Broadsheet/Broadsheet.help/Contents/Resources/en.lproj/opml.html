OPML Import & Export

Migrate feeds from or to another reader.

What is OPML?

OPML is a standard file format used by RSS readers to share feed lists. If you're switching from another reader (like Feedly, NetNewsWire, or Reeder), you can export your feeds as an OPML file and import them into Broadsheet Reader.

Importing Feeds

  1. In your previous reader, look for an "Export" or "Export OPML" option and save the file
  2. In Broadsheet Reader, go to File > Import Feeds from OPML
  3. Select the OPML file
  4. Broadsheet Reader will create any groups defined in the file and add all feeds, skipping any you already have
Tip: Duplicate feeds are automatically skipped during import, so it's safe to import the same file twice.

Exporting Feeds

  1. Go to File > Export Feeds as OPML
  2. Choose where to save the file
  3. The exported file includes all your feeds organized by group

The export preserves your full group structure, so importing it into another reader will recreate your organization.
